Cara Menjalankan Proyek
1. Menggunakan Apache NetBeans (Cara Termudah)
Buka proyek projek-kalkulator-bmi di Apache NetBeans.
Klik tombol Run (atau tekan tombol F6 di keyboard).
Jika sebelumnya ada perbaikan kode/FXML, tekan Clean and Build (Shift + F11) terlebih dahulu, lalu klik Run (F6).
2. Menggunakan Terminal / Command Prompt
git clone (https://github.com/jipydev/Calculator-BMI-JavaFX.git)
cd Calculator-BMI-JavaFX
mvn clean javafx:run
